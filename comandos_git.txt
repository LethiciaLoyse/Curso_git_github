git init. -> cria um repo git na pasta atual 
git status -> mostra o status do trabalho (de cada arquvio)
git add nome_arquivo -> adciona o arquivo para ser commitado 
git commit -m "msg" -> faz um commit do que estava para ser commitado
git log -> mostra todo o histórico de commit

## fluxo de trabalho
1- criar o diretório
2 - inicia o git dentro do diretório criando (git init . )
3- edita ou cria arquivos
4- git status 
5- git add <nome arquivo>
6- git status
7- git commit -m "mensagem"
8- git status
9- volta para o passo 3
